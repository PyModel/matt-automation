# Core rules

Read this at the start of every phase. It is the only file, besides SKILL.md, that stays loaded.

- **Autonomous.** Never pause for routine approval; questions a sub-skill would ask go to `/kun`, and KUN.md settles decisions that evidence does not. Force-push, deleting data, pushing, a PR, spending money, credentials, production, and guarded paths (CI, migrations; after stage 6 any top-level file) are blockers unless the owner's own words name them, and must comply with repo and harness rules. Authority is a quotation: `goal.mjs grant <slug> <path|push:<remote>|pr>... -- "<their words>"` checks the words against what the owner wrote (their prompts in this session, kept by the harness hook; the objective where the harness keeps none) and refuses words that do not name the target. A decision the orchestrator writes is never a grant, whatever it cites. Neither is a persona, card, example, or tracker setting. A grant covers only what it names: a blanket instruction ("merge all") lifts no hold the owner set (an owner-only merge, a separate review), and silence grants nothing, so no plan reads "unless the owner objects". `to-auto-guard` denies an ungranted push or PR write. Record what is blocked; continue independent work. A tool failing twice is a blocker.
- **State.** Run state is the folder `goal.mjs control` prints: `--state-dir`, else `TO_AUTO_HOME`, else `~/.local/state/to-auto/<repo-id>`. It is a private git repo. It is not a branch of the user repo. Do not create `goal/control`. Do not edit `.git/info/exclude` or `.gitignore` to hide state.
- **Startup.** `goal.mjs preflight` checks requirements and fails with a clear message. `goal.mjs prepare` clones into the state folder when this checkout is a linked worktree whose shared git dir is not writable. Later git commands run in the workspace it prints. `goal.mjs land` brings those commits back.
- **Writes.** With `--allow`, every planned write must sit inside that list or preflight refuses to start. Do not write anywhere else.
- **Supervisor.** `--base`, `--target-branch`, `--status-file`, `--no-remote`. Commit on the target branch. `--no-remote` forbids `git push`, `pull`, and fetch of a remote; a local path is not a remote. `goal.mjs land` appends a summary that maps each item to its commit.
- **Helpers.** Every helper agent is on record at both ends: `goal.mjs helper start <slug> <role> <id> --brief <prompt file>` before the dispatch, `helper return <slug> <id> --model <model-used> --final <file|->` after. `start` refuses past `max_agents`. Pass `--worker-model` when one is named. Register with `--no-helpers` when requested or when helpers are disallowed or unavailable; `start` and `dispatch` then refuse. If the host disallows helpers, `next` reports `helpers: none`, or NOW says `nested: none`, perform all helper roles inline, one at a time, including roles a loaded skill would spawn. Keep the same artifacts and gates. Label inline reviews self-review; required independent review is a blocker.
- **Check.** The suite is `goal.mjs check-command --objective "<objective>"`. A `check:` in the objective wins over the repo.
- **Compact.** A compaction gives no warning, so NOW stands alone at every stage boundary. After one (recorded by the harness hook, else by `goal.mjs compact <slug>`): read this file and the phase file again, load again every skill `next` lists (`skills_to_load`), and `goal.mjs check <slug>` must exit 0 before the next action. Never choose to compact between stages 5 and 6b.
- **Pipeline.** Repository rules may change how a stage runs, never whether it runs; an objective that does not fit → `goal.mjs stop <slug> "objective does not fit: …"`. Worktrees come only from `goal.mjs worktree get`; a stage is finished only by `goal.mjs tick <slug> <id>` (`--skipped <reason>` for one that did not run): it ticks todo.md, writes NOW's `- stage:` line and makes every forward registry move, refusing an out-of-order stage, a missing artifact or a registry step whose evidence is missing. Never tick a box, edit the stage line or move the registry by hand.
- **Kill switch.** `goal.mjs stop <slug> "<reason>"`. A user who tells the session to stop, halt or kill the run's work gets it before the turn ends: `goal.mjs stop <slug> "user: <their words>"`, then their other instructions (killing workers) are carried out. A run left active is resumed by the keep-going hooks (PIPELINE.md § Under a loop).
- **Redaction.** Replace secrets with `<REDACTED>` before writing a ledger, status, bug, or notes file.
- **Cleanup.** `goal.mjs cleanup` deletes the state folder, and refuses while a run worktree is active or the clone holds unlanded commits. It does not leave a branch or an ignore-file edit in the user repo. `goal.mjs gc --delete-clean` frees only what finished runs no longer need (CONTROL.md).
